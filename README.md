# MOJi Study Extension

A Chrome extension that adds a "Read-Aloud Study" page to the [MOJi dictionary](https://www.mojidict.com/) site. Paste Japanese, and it shows each sentence with readings, a translation, word cards and the sentence patterns used, and reads it aloud sentence by sentence with repeat and loop. A small local server provides the speech (Microsoft Edge voices through edge-tts), word splitting, sentence-pattern detection and Google/Bing translation.

To install and use it, see [docs/usage.md](docs/usage.md). All other docs start at [docs/README.md](docs/README.md).
